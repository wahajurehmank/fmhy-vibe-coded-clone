# 1.1.0

- Added toggleable brutalism, bento grid, claymorphism, maximalism and glassmorphism layouts, alongside Classic.
- Reduced visual clutter, muted accents, improved mobile layout and readability.
- Added saved preferences before first paint and a keyboard-accessible native theme dialog.
- Reduced speculative requests, cached searchable rows, bounded upstream batches and added failure backoff.
- Improved refresh behavior so background updates preserve reading filters.
- Added nonce-based script controls, security headers, stricter input and local-storage validation.
- Updated Next.js to 16.4.0 and added security regression checks and Dependabot configuration.
- Preserved FMHY content, search, automatic refresh, fallback behavior and Vercel/Netlify deployment setup.
